# Kian Adl Toos Landing Page

Static landing page built with plain HTML, CSS and JavaScript. Suitable for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `script.js`

## Run locally
Open `index.html` in your browser.

## Publish on GitHub Pages
1. Create a repository.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

## Images
The current draft uses image URLs from `kianadltoos.ir` / `kianadltoos.com`.
For a fully independent site, download approved originals and place them inside an `assets/` folder, then replace image URLs in `index.html`.

## Notes
The visual system is a new implementation inspired by the reference website's industrial/company context rather than a direct copy.
